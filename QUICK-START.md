# Quick Start Guide - AI Code Builder

Welcome to AI Code Builder! This guide will help you get started building amazing web applications with AI.

## 🚀 Getting Started

### Step 1: Access the Editor

Visit [https://securemail.ltd/editor](https://securemail.ltd/editor)

No login required! The app works in guest mode by default.

### Step 2: Configure Your API Key

1. Click the **Settings** (⚙️) button in the top right
2. Get an API key from [OpenRouter](https://openrouter.ai/keys) (free credits available)
3. Paste your API key in the settings modal
4. Select your preferred AI model (Claude 3.5 Sonnet recommended)
5. Click **Save Settings**

Your API key is stored locally in your browser and never sent to our servers.

### Step 3: Start Building

#### Option A: Use the Chat Interface

In the left sidebar, describe what you want to build:

```
Create a landing page for a coffee shop with a hero section, 
menu, and contact form
```

The AI will generate complete HTML, CSS, and JavaScript for you!

#### Option B: Use a Template

On the homepage, click **Browse Templates** to see ready-made examples:
- Portfolio websites
- Landing pages
- Interactive dashboards
- And more!

### Step 4: Edit Your Code

- **File Tree** (left middle): Switch between files
- **Code Editor** (center): Monaco editor with syntax highlighting
- **Live Preview** (right): See changes in real-time

### Step 5: Export Your Project

Click the **Export** button in the top navigation to download your project as a ZIP file.

## 💡 Tips & Tricks

### Writing Good Prompts

**✅ Good Prompt:**
```
Create a responsive pricing table with 3 tiers (Basic, Pro, Enterprise).
Include monthly/yearly toggle, features list, and call-to-action buttons.
Use a gradient background and modern card design.
```

**❌ Bad Prompt:**
```
make a pricing page
```

### Best Practices

1. **Be Specific**: Include details about layout, colors, and features
2. **Break It Down**: For complex projects, build one section at a time
3. **Iterate**: Ask the AI to modify or improve existing code
4. **Test Often**: Check the live preview frequently
5. **Export Regularly**: Download backups of your work

## 🔧 Keyboard Shortcuts

- `Ctrl/Cmd + S`: Save (auto-saves to browser)
- `Ctrl/Cmd + F`: Find in editor
- `Ctrl/Cmd + /`: Toggle comment
- `Alt + Click`: Multiple cursors

## 📱 Mobile Support

The editor works on tablets and modern mobile devices, but desktop is recommended for the best experience.

## 🆘 Troubleshooting

### "API key not configured"
→ Open Settings and add your OpenRouter API key

### Preview not updating
→ Click the refresh button in the preview panel

### Code not generating
→ Check your API key is valid and you have credits

### Console errors
→ Open browser DevTools (F12) to see detailed error messages

## 🚀 Advanced Usage

### Custom Templates

You can create your own templates by:
1. Building a project
2. Exporting it
3. Sharing the ZIP file

### Multiple Files

Create complex projects with:
- `index.html` - Main page
- `styles.css` - Stylesheet
- `script.js` - JavaScript
- Additional pages (about.html, contact.html, etc.)

### Libraries & Frameworks

You can use CDN links in your HTML:
```html
<!-- Tailwind CSS -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Alpine.js -->
<script defer src="https://unpkg.com/alpinejs@3.x.x/dist/cdn.min.js"></script>

<!-- Chart.js -->
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```
